    软件推荐

    发表于 2025-02-26 更新于 2026-08-10 分类于 汇总 本文字数： 5.5k 阅读时长 ≈ 20 分钟

    [!info] 使用说明

    • 按使用场景和操作系统分类，链接优先使用官网或官方仓库。
    • “个人备份”表示原记录未提供公开下载地址；付费软件建议优先通过官网或应用商店获取。
    • 软件的价格、免费额度和系统支持可能变化，安装前请以官网说明为准。

    快速选择

    场景 推荐
    浏览器 Chrome / Firefox / Edge；注重隐私可选 Brave
    笔记与知识库 Obsidian / Notion
    代码编辑器 VS Code / JetBrains / Zed；AI 编程可选 Cursor / Void
    界面设计与原型 Figma / Pencil
    API 调试 Apifox / Postman；MQTT 使用 MQTTX
    密码管理 1Password / Bitwarden
    文件同步与传输 Syncthing（设备直连）/ LocalSend（局域网传文件）/ 坚果云（云端同步）
    内网组网 Tailscale；端口映射可选 frpc-desktop
    macOS 启动器 Raycast / Alfred
    Windows 效率工具 PowerToys / uTools / Everything
